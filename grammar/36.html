比較句型（より／いちばん／どちら）

句型

とうきょうは おおさかより おおきいです。　　東京比大阪大。（兩樣：より）
おおさかより とうきょうの ほうが おおきいです。　　比起大阪，東京比較大。（兩樣：ほう）
コーヒーと こうちゃと どちらが すきですか。　　咖啡和紅茶，喜歡哪一個？（問兩樣）
くだものの なかで なにが いちばん すきですか。　　水果裡最喜歡什麼？（三樣以上）

比較只有兩種情況：兩樣比，或一群裡挑第一。兩樣用 より／ほう／どちら，一群用 なかで／いちばん。整章就這兩格，下面一格一格拆。

兩樣比：A は B より〜

日文中文
とうきょうは おおさかより おおきいです。東京比大阪大。
でんしゃは バスより べんりです。電車比公車方便。
なつは ふゆより たのしいです。夏天比冬天開心。
きのうは きょうより さむかったです。昨天比今天冷。

より 掛在比較的基準後面，意思是「比起 B」。

⚠️ 台語、華語都講「A 比 B 較 大」——「比」站在 B 的前面，形容詞前面還要多一個「較 khah」。日語反過來：より 站在 B 的後面，形容詞前面什麼都不加。×とうきょうは より おおさか おおきい 是照華語語序直翻。

  • より 的漢字是「依り」，古語是「從〜」的意思，跟第 11 章 にほんから 的 から 是親戚：「從大阪那邊看過去，東京大」。正式書信裡 より 到今天還當「從」用。
  • 形容詞照第 3、4 章的樣子放：い形容詞 おおきいです、な形容詞 べんりです（不加 な，×べんりなです）。
  • 時態只變最後的形容詞：さむかったです（第 3 章）、しずかでした（第 4 章）。より 永遠不變。
  • 語序可以換：おおさかより とうきょうは おおきいです 也通，但比較少見——基準放前面的時候，通常改用下一節的 ほう。

ほう：「這一邊」

日文中文
おおさかより とうきょうの ほうが おおきいです。比起大阪，東京比較大。
バスより でんしゃの ほうが べんりです。比起公車，電車比較方便。
わたしは いぬより ねこの ほうが すきです。比起狗，我比較喜歡貓。

ほう 的漢字是「方」——台語文言音 hong，h 子音、ong 韻對到日語的 ほう。意思是「這一邊、那一方」，就像台語講「這爿較好」：兩樣東西擺左右兩邊，挑出「東京那一邊」。

  • 名詞＋の＋ほう：ほう 是名詞，前面的名詞要用 の 接（第 11 章名詞修飾名詞），×とうきょうほうが。
  • ほう 後面用 が，不用 は：被挑出來的那一邊是新資訊、是答案，用 が 點名（跟第 10 章「能力的對象用 が」一樣是 が 的地盤）。×とうきょうの ほうは。
  • すき／きらい／じょうず／へた 的對象本來就用 が（第 20 章 ビールが すきな），所以 ねこの ほうが すきです 裡的 が 一個抵兩用。
  • より 那一半可以省：前面已經在講兩樣東西時，直接 とうきょうの ほうが おおきいです 就夠了。
  • 動詞＋ほうが（〜たほうがいい「最好〜」）之後會學，這章只放名詞。

問兩樣：A と B と どちらが〜ですか

問答
コーヒーと こうちゃと どちらが すきですか。コーヒーの ほうが すきです。
でんしゃと バスと どちらが べんりですか。でんしゃの ほうが べんりです。
いぬと ねこと どちらが すきですか。どちらも すきです。
  • どちら 是單字表 こそあど 的「方向」那一列：こちら（這邊）／そちら（那邊）／あちら（那邊遠處）／どちら（哪邊）。今天用的就是「哪一邊」——兩樣擺左右，問哪一邊。
  • どっち 是 どちら 的口語版，對朋友講：コーヒーと こうちゃと どっちが すき？（普通體問句不加 か、語調上揚，第 26 章）。
  • A と B と 的第二個 と 可以換成 では、は，口語也常整個省掉：コーヒーと こうちゃ、どちらが すきですか。と＝「和」，跟第 29 章 と おもう 的 と 同形異工。
  • 回答用 ほう，不用 いちばん（兩樣沒有「第一」可講）。
  • 兩個都＝どちらも：も 把 が 擠掉（第 20 章 ×どちらがも）。どちらも すきです＝兩個都喜歡；後面接否定 どちらも すきじゃ ありません＝兩個都不喜歡。

一群裡挑第一：〜の なかで〜が いちばん〜

問答
くだものの なかで なにが いちばん すきですか。みかんが いちばん すきです。
きせつの なかで いつが いちばん すきですか。なつが いちばん すきです。
にほんの まちの なかで どこが いちばん すきですか。きょうとが いちばん すきです。
かぞくの なかで だれが いちばん りょうりが じょうずですか。あねが いちばん じょうずです。
  • いちばん（一番）妳本來就會（動漫必備詞）——台語文言音 一 it、番 huan；番 的古代聲母是 p 類，台語演變成 h，日語留成濁的 ば（同發音規則 2：は行古代念 p，演變成 h／b／p）。意思就是台語的「上 siōng」：上好、上愛。
  • なか＝裡面（位置詞，うえ⇄した、なか⇄そと 那一組），なかで＝「在〜當中」。這個 で 是「範圍」的 で，跟第 16 章 カードで（手段）不是同一個用法，第 48 章會把 で 的用法整理在一起。
  • 群組名詞＋の＋なかで：×くだもの なかで（漏 の，同上一節 ほう 前面要 の）。
  • 被挑出來的第一名也用 が（同上一節 ほうが）。

比較用的疑問詞：完整一張表

疑問詞問什麼用在狀態
どちら／どっち兩樣裡哪一邊A と B と どちらが今天
なに什麼東西〜の なかで なにが已學
どれ哪一個（列出來的選項裡）〜の なかで どれが已學（こそあど 物那一列），比較用法今天
だれ哪個人〜の なかで だれが已學
どこ哪個地方〜の なかで どこが已學
いつ什麼時候〜の なかで いつが已學

判斷只有一條：兩樣用 どちら，三樣以上用其他五個。三樣以上時，東西用 なに 或 どれ 都可以（選項擺在眼前、一個一個點名的感覺用 どれ），人用 だれ、地方用 どこ、時間用 いつ。疑問詞的完整整理（どんな 等）在第 52 章。

最容易錯的地方

對錯錯在哪
とうきょうは おおさかより おおきいです×とうきょうは より おおさか おおきいです照華語「比 B」語序，より 要放在 B 後面
とうきょうの ほうが おおきいです×とうきょう ほうが おおきいです名詞接 ほう 要 の
とうきょうの ほうが おおきいです×とうきょうの ほうは おおきいです挑出來的那一邊用 が
A と B と どちらが すきですか×A と B と どれが すきですか兩樣用 どちら
ねこの ほうが すきです×ねこが いちばん すきです（回答兩樣的問題）兩樣沒有「第一」，用 ほう
くだものの なかで なにが いちばん すきですか×くだものの なかで どちらが いちばん すきですか三樣以上不用 どちら
この まちは とうきょうより しずかです×しずかなですな形容詞當述語不加 な（第 4 章）
どちらも すきです×どちらがも すきですも 擠掉 が（第 20 章）

用在哪裡

  • 點餐、買東西：コーヒーと こうちゃと どちらが いいですか（要咖啡還是紅茶？）——店員常這樣問，回答 コーヒーを おねがいします 或 コーヒーの ほうが いいです 都行。
  • 聊天：きせつの なかで いつが いちばん すきですか，是自我介紹時的標準話題。
  • 「A 沒有 B 那麼〜」（A は B ほど〜ない）之後會學，這章只教「比較〜」和「最〜」。
